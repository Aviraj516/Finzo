 # 🌱 Finzo – AI Powered Financial Companion

**Finzo** is a gamified AI-powered personal finance assistant that helps users control overspending and develop healthy saving habits.
Instead of just tracking expenses like traditional finance apps, Finzo uses **behavioral analytics, risk scoring, and gamification** to encourage better financial decisions.

# 📊 Problem Statement

Most financial tracking apps only show **where money was spent**, but they fail to change user behavior.

Studies show that **78% of users abandon finance apps within the first 30 days** because:

* The apps only track expenses
* They provide little motivation to improve habits
* There is no engagement or reward system

As a result, users continue overspending and struggle to build savings.

---

# 💡 Solution

Finzo introduces a **Financial Vitality Score (VitalScore)** that evaluates a user's spending behavior in real time.

Instead of only tracking money, Finzo:

* Analyzes spending behavior
* Calculates financial risk
* Rewards good financial habits
* Uses gamification to keep users engaged

Users can **see their financial health grow like a virtual tree** as they save more money.

---

# 🚀 Key Features

### 📊 Financial Vitality Score

Measures financial health based on the ratio of:

* Needs
* Wants
* Savings

### ⚠️ Overspending Detection

Detects when users are about to exceed their budget and sends alerts.

### 🌱 Gamified Savings System

Users earn **XP points** for maintaining good financial habits.

Tree Growth Levels:

* 🌱 Seed
* 🌿 Sapling
* 🌳 Small Tree
* 🌳 Lush Tree

### 🤖 AI Financial Insights

The backend analyzes spending patterns and provides recommendations.

### 🎯 Goal Tracking

Users can set financial goals and track progress visually.

---

# 🧠 How the System Works

```
User spends money
      ↓
Flutter App captures transaction (SMS / manual entry)
      ↓
Expense sent to FastAPI backend
      ↓
Backend calculates:
   • Risk Score
   • Financial Vitality Score
   • XP Points
      ↓
Gamification system updates:
   • Tree growth
   • Badges
   • Daily challenges
      ↓
User receives alerts and insights
```

# 📈 Financial Vitality Score Formula

```
Risk Score = (Spent Amount / Allocated Budget) × 100
```

XP System:

| Risk Score | XP Reward |
| ---------- | --------- |
| < 50       | +10 XP    |
| 50–80      | +5 XP     |
| > 80       | 0 XP      |

Tree growth depends on XP levels.
